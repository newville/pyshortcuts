Installation
------------------

The latest version of `pyshortcuts` is |release|, which can be
installed with::

    pip install pyshortcuts

Pyshortcuts requires the `charset-normalizer`, `platformirs`, and
`tabulate` packages.  On Windows, pyshortcuts also requires the
`pywin32` package.  These packages will be installed if needed.

To use the pyshortcut GUI, the `wxPython` package is required, which
can be installed with::

    pip install "pyshortcuts[gui]"

For development versions, see  https://github.com/newville/pyshortcuts
